# 삼일핏 (Samil Fit)

다이어트 목표 · 야근 시간 · 식대 버짓을 넣으면 용산 일대 식당과 편의점 메뉴로 1주일 맞춤 식단과 칼로리를 짜주는 앱.
2026 Discover B-4조. **화면 설계서 v0.8** 기준으로 구현.

## 실행 · 배포
```bash
python3 -m http.server 8001 --directory samil-fit
```
- `index.html` 하나(CSS·JS 포함) + `data/restaurants.json`. 빌드 없음. 이 폴더를 저장소 루트로 두면 Vercel에 그대로 배포됨.
- `file://`로 직접 열면 JSON을 불러오지 못하니 http 서버로 열 것.

## 데이터 (`data/restaurants.json`)
설계서 5-1 형식, 메뉴 1개 = 객체 1개.
```json
{ "id": "...", "restaurant": "...", "area": "ls|yr|ipark|cvs", "menu": "...", "price": 12900,
  "kcal": 650, "source": "official|est", "open": { "lunch": true, "dinner": true, "late": false },
  "carb": null, "protein": null, "fat": null, "note": "일요일 휴무" }
```
- `note`: 엑셀 '비고' 칸. S3 메뉴 상세 시트에 📝 한 줄로 표시 (설계서 추가 항목, 팀 합의).
- 원본 엑셀: `data/menu.xlsx` (첫 번째 시트만 사용, 다른 시트는 무시). 현재 51곳 · 122개 메뉴.

## 메뉴 데이터 업데이트 (데이터팀용)
사용자 제보는 앱의 "메뉴 제보하기" → [구글 폼](https://docs.google.com/forms/d/e/1FAIpQLSeQ0JX40fYWNZvibPIMkDMBatAE-K-me1dcSiktMiRDEwXa4A/viewform)으로 들어옴 → 데이터팀이 확인 후 엑셀에 추가.

1. 엑셀 첫 번째 시트에 행 추가 · 수정 (열 순서 · 제목은 그대로, 영업 여부는 O/X, 출처는 공식값/추정치)
2. 파일 이름을 **`menu.xlsx`** 로 저장
3. GitHub 저장소 → `data` 폴더 → **Add file → Upload files** → `menu.xlsx` 끌어다 놓기 → **Commit changes**
4. **Actions** 탭에서 "메뉴 데이터 반영"이 ✅ 이면 끝 (1~2분 뒤 앱에 반영)
   - ❌ 이면 실패 로그에 "N행 식당 / 메뉴: 이유"가 나옴 → 엑셀 고쳐서 다시 업로드. 고치기 전까지 앱은 이전 데이터 그대로

- 구글 폼 구역 선택지('AP 본사 B1')처럼 띄어쓰기만 다른 값은 그대로 붙여 넣어도 됨.
- 새 구역 이름을 쓰려면 `tools/xlsx_to_json.py`의 `AREA` 표에 추가해야 함 (빌드팀에 요청).
- 로컬에서 미리 확인: `python3 tools/xlsx_to_json.py` (기본값 data/menu.xlsx)

## 설계서에 없던 부분 — 팀 확인 후 결정한 것 (10/03)
- 치팅 끼니 목표 칼로리: **800 kcal** (적당한 치팅 모드 끼니 목표와 동일). 버짓은 일반 끼니와 같음.
- 칼퇴인 날 저녁을 치팅 끼니로 고르면 **치팅 저녁을 추천**함 (저녁 식대 버짓, 구역 제한 없음, 하루 목표·주간 버짓에 포함).
- 주간 버짓 = 점심 버짓 × 5 + 저녁 식대 버짓 × (저녁을 추천하는 날 수). 심야 야식 가격은 식비 합계에는 들어가지만 버짓 식에는 없음 (설계서 그대로).
