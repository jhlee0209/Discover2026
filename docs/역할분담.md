# 역할 분담안 (초안) — 9명 전원 AI로 기능 1개 이상

> 가이드 규칙: 모든 조원이 최소 1개 기능 구현에 AI를 직접 활용해야 하고, 특정 조원이 개발을 전담하면 감점됩니다.
> 같은 파일을 동시에 고치지 않도록 **담당 파일**을 나눴어요. 작업 전 톡방에 "지금 ○○ 작업 중" 한 줄 남기기.
> Free 플랜 조원은 Claude Chat/Artifact에서 결과물을 만든 뒤 빌드팀에게 파일로 넘기면 됩니다.

| # | 담당 기능 | 담당 파일 | 팀 | Claude에게 이렇게 요청 (예시) |
|---|---|---|---|---|

## 공통 규칙
- `vendor/` 폴더는 수정 금지 (AI 모델·라이브러리)
- JSON 파일은 수정 후 쉼표·따옴표 오류가 없는지 Claude에게 "JSON 문법 검사해줘"로 확인
- 실제 개인정보·사내 정보 사용 금지 (샘플 인물은 가상)
- 잘 동작할 때마다 GitHub main에 올리기 → Vercel 자동 배포 → 시크릿 창·휴대폰 확인
